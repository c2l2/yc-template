# Team

> the upcoming weekly meeting note, not in this file.

Use stable member IDs so task ownership and Git authorship can be matched
without guessing. Add every Git author name or email that a member uses in this
repository.

## Management Rules

- The manager approves roles, capacity, and assignment constraints.
- Git identity is used only to locate relevant committed work. It is not a
  measure of productivity or sole authorship.
- AI must report an ambiguous author mapping instead of guessing.
